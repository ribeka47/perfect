About This Project
This website is dedicated to the FIFA World Cup, celebrating one of the world's greatest sporting events. Although I am not a football fan, I have always been fascinated by the excitement, passion, and global unity that the tournament brings. Like millions of people around the world, I found myself captivated by the World Cup's unforgettable moments, legendary players, and rich history.
This project was created to showcase the spirit of the FIFA World Cup through a clean and engaging website built using only HTML and CSS.
